# Kotoba Lyrics v1.6.7

统一使用 LYRIVA 获取歌词，移除 GENIUS 备用来源，并清理不再使用的设置与辅助代码。

## 更新内容

- 歌词来源仅保留 LYRIVA，移除 GENIUS 的设置入口与请求链路。
- 启动时清理旧 GENIUS Token，不再复用旧 GENIUS 歌词缓存。
- 移除旧歌词匹配器、社区及作者署名相关逻辑与样式。
- 移除无效的 TTML 设置，清理未调用的翻译、授权、弹窗和播放器辅助接口。

## 验证

- 52 个测试文件通过。
- Lint、格式检查、TypeScript 类型检查及生产构建通过。
- 本次功能改动已在本地 Spotify 中验证启动正常。

## 安装与更新

已安装用户可在「设置 → 高级 → 版本与更新」检查更新，下载完成后重新加载 Spotify。也可从 Marketplace 更新，或下载本页安装附件 `kotoba-lyrics.js`，覆盖 Spicetify 的 `Extensions` 文件夹中的同名文件，再执行 `spicetify apply`。
