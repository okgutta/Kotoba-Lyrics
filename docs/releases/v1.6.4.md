# Kotoba Lyrics v1.6.4

同步 Spicy Lyrics 6.3.142 的性能、音量、弹窗及 Spotify 1.3.3 兼容修复，保留 Kotoba 的翻译功能、中文设置与进度条键盘操作。

## 更新

- 「设置 → 外观」新增「限制动画帧率」，支持 15–240 FPS，默认关闭，开启后的默认上限为 60 FPS。
- 歌词、动态背景、滚动跟随和轮询共享动画调度，减少常驻 GPU 图层、重复样式写入及昂贵 CSS 重算。
- 音量胶囊支持点击喇叭静音、再次点击恢复原音量，也可以从喇叭图标处开始拖动。
- 弹出歌词适配窄高与矮小窗口，最小视口为 260×180，歌词、封面和渐隐区域随窗口调整。
- 弹出歌词开关即时切换播放栏入口；启用时替代 Spotify 的迷你播放器按钮，并在 Spotify 重建控件后保持生效。

## 修复

- 修复新版 Spotify 播放栏按钮延迟挂载或被替换后消失、歌词页等待主区域挂载时无法自动恢复的问题。
- 补全 Spotify 1.3.3 右侧歌词卡片、动态背景、影院视图、工具提示、通知位置和头像菜单设置入口的兼容。
- 修复封面延迟加载时歌词卡片位置错误、右侧动态背景出现横向硬边，以及封面透明度影响主题装饰的问题。
- 修复弹出歌词窗口拖动音量后，返回主窗口导致音量突然归零的问题，补全触摸取消与拖动清理。
- 避免覆盖第三方主题的播放栏布局，保留新版 Spotify 原生播放时间布局。
- 修复爱心按钮边缘悬停闪烁、小弹窗活动歌词滚入底部渐隐区的问题。
- 修复简洁歌词模式回退时高亮残留，以及部分高刷新率屏幕限帧偏高的问题。

## 进度条样式

玻璃进度条可在「设置 → 高级 → 新进度条样式」开启。关闭时保留带圆点的旧样式；本次更新保留已有选择。

## 验证

- 52 个测试文件通过，覆盖限帧、音量与进度拖动、弹窗尺寸、页面与控件挂载、侧栏和主题布局等回归场景。
- Lint、格式检查、TypeScript 类型检查及生产构建通过。

## 安装与更新

已使用兼容加载器的用户可通过扩展内自动更新获取新版。也可从 Marketplace 更新，或下载本页安装附件 `kotoba-lyrics.js`，覆盖 Spicetify 的 `Extensions` 文件夹中的同名文件，再执行 `spicetify apply`。

上游参考：[Spicy Lyrics 6.3.98…6.3.142](https://github.com/Spikerko/spicy-lyrics/compare/6.3.98...6.3.142)。
