# Kotoba Lyrics v1.6.0

本次覆盖更新现有 1.6.0 安装包，版本号保持不变。

## 本次更新

- 软件更名为 **Kotoba Lyrics**，歌词请求的 `X-Client-Name` 同步更新。
- 更新页并入设置，统一分组列表、按钮和返回导航，移除独立紫色弹窗。
- 仓库与自动更新地址迁移至 `okgutta/Kotoba-Lyrics`。
- 保留后台下载、文件校验、离线备用版本和启动失败回退。
- 关键版本可通过最低支持版本机制要求更新，本次默认未启用该限制。

## 安装与覆盖

已经安装 1.6.0 的用户不会收到更高版本提醒，请手动覆盖一次：

1. 下载本次 Release 的 `kotoba-lyrics.js`。
2. 放入 Spicetify 的 `Extensions` 文件夹。
3. 依次执行 `spicetify config extensions lyrivamusic.js-`、`spicetify config extensions kotoba-lyrics.js` 和 `spicetify apply`。

安装文件已统一更名为 `kotoba-lyrics.js`，插件商店显示 **Kotoba Lyrics**。原有设置与缓存保留，后续新版本继续通过新仓库自动更新。商店若仍显示旧名称，请完整退出并重新打开 Spotify 后再搜索。
