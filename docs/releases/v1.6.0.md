# lyrivaMusic v1.6.0

## 更安静的自动更新

- 普通更新先在后台下载并校验，准备好后才弹出提示。
- 可选择「立即重新加载」或「下次启动生效」，关闭提示也会保留已下载的更新。
- 每个版本只自动提醒一次，重启后保留记录；正在编辑设置时不会抢占弹窗。
- 后台检查失败不打断使用，可从「版本与更新」查看错误、重试或前往发布页手动安装。

## 关键版本更新

- 增加最低支持版本机制，只有确实需要停用旧版时才启用，日常更新保持可推迟。
- 必须更新时会说明原因并暂停歌词功能，可以关闭提示继续使用 Spotify。
- 下载失败、断网或回退不会解除已确认的最低版本限制；已知启动失败的包不会被反复下载。
- 本次发布默认未启用最低支持版本限制。

## 从旧版本升级

本次升级更新加载器到协议 2。旧加载器无法通过后台下载更新自身，需要手动安装一次：

1. 下载本次 Release 的 `lyrivamusic.js`。
2. 覆盖 Spicetify 的 `Extensions/lyrivamusic.js`。
3. 执行 `spicetify apply` 并重新打开 Spotify。

完成后，后续兼容版本继续自动更新，无需每次手动替换。
