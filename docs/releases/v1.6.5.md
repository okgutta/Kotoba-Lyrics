# Kotoba Lyrics v1.6.5

修复前奏、间奏圆点上浮后原位置残留灰色圆影，以及圆点出现双重轮廓的问题。

## 修复

- 逐字歌词和逐行歌词的间奏提示均由圆点自身绘制，移除父行重复绘制的字形，保留变亮、上浮和发光动画。
- 补回上游已有的逐字歌词父行绘制修复，避免移动中的词与字母出现重影。
- 保留普通逐行歌词、静态歌词、简洁模式和译文的正常显示。

## 验证

- 在 Chrome 中复现上游与本地间奏重影，并验证修复前后效果。
- 20 种浏览器样式检查通过，覆盖歌词类型、圆点与正文、普通／简洁／紧凑／全屏模式。
- 本地 Spotify 已确认加载修复代码与样式；52 个测试文件、Lint、格式、类型检查及生产构建通过。

## 安装与更新

已安装用户可在「设置 → 高级 → 版本与更新」检查更新，下载完成后重新加载 Spotify。也可从 Marketplace 更新，或下载本页安装附件 `kotoba-lyrics.js`，覆盖 Spicetify 的 `Extensions` 文件夹中的同名文件，再执行 `spicetify apply`。
