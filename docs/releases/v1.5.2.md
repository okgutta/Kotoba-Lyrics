# lyrivaMusic v1.5.2

## 性能与兼容性

- 合入 Spicy Lyrics 6.3.98 的相关修复，兼容 Spicetify 2.45.1 及更早版本在 Spotify 1.3.x 上的滚动扫描问题，减少歌词换行时的卡顿。
- 优化歌词、侧栏动态背景和播放栏的 CSS 选择器，减少歌词更新触发的整页样式重算。
- 改善正在播放面板歌词卡片的展开与收起，支持快速连续操作，并在卡片被移除时清理未完成的状态切换。
- 修复部分 Spotify 版本使用不同进度条容器时的播放栏布局。

保留 lyrivaMusic 的歌词源、翻译、阅读设置和自动更新机制。
