# Kotoba Lyrics v1.6.3

## 更新

- 适配 Spotify 1.3.3 的主区域结构，歌词页和全屏入口使用保留的主内容容器定位，不再依赖已移除的 `.Root__main-view` 类名。
- 新版 Spotify 使用原生的播放时间布局；旧版仍保留原有的时间更新防回流处理。
- Marketplace 标签改为「中文歌词、双语歌词、逐字歌词、同步歌词、歌词翻译、罗马音」，保留 `kotoba` 品牌标签，方便中文用户识别和搜索。

## 修复

- 修复更新 Spotify / Spicetify 后，歌词已获取成功但歌词页整页空白的问题。
- 修复找不到页面容器时仍被标记为“已打开”的问题，容器可用后再次打开能够正常挂载。
- 修复播放栏全屏入口和按住 Shift 打开歌词时仍等待旧页面结构的问题。
- 修复歌词页打开后，左侧已播放时间与进度条重叠的问题，恢复时间与进度条之间的正常间距。
- 修正歌词视口高度样式中的选择器拼写，并保留旧版布局兼容。

## 验证

- 在 Windows、Spotify 1.3.3.264、Spicetify 2.45.3 上验证歌词显示、关闭后重新打开，以及播放时间与进度条布局。
- 增加新版页面结构、多个滚动容器、缺少挂载容器后重试及旧版结构的回归测试。

## 安装与更新

已使用兼容加载器的用户可通过扩展内自动更新获取新版。也可从 Marketplace 更新，或下载本页唯一安装附件 `kotoba-lyrics.js`，覆盖 Spicetify 的 `Extensions` 文件夹中的同名文件，再执行 `spicetify apply`。

本次修复针对页面和进度条显示；歌词服务请求超时需重试，GitHub 更新检查限流需稍后再试。
